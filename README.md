# Sistema de Gestión de Tareas Académicas

## Autor
Tiago Alejandro Insuasti Guerrero

## Fecha
Junio 2026

## Objetivo
Desarrollar una aplicación en Python que permita organizar tareas académicas de forma sencilla y eficiente.

## Funcionalidades
- Agregar tareas.
- Mostrar tareas.
- Completar tareas.
- Eliminar tareas.
- Buscar tareas.
- Salir del sistema.

## Tecnologías utilizadas
- Python
- GitHub

## Relación con la asignatura
Este proyecto integra conceptos de análisis de sistemas, programación, diseño de software y aplicación de nuevas tecnologías en la sociedad.
